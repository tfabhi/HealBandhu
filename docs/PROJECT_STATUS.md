# Project status and implementation boundaries

This repository is a reconstructed starter scaffold based on the HealBandhu project brief.

## Implemented in this starter
- Flutter landing screen
- Demo chat interface with fixed safety response
- Image selection and on-device OCR text extraction
- FastAPI root and health-check endpoints

## Not implemented / requires separate work
- Actual AI chatbot, Dialogflow or Rasa connection
- Medical symptom triage or diagnosis
- Automated expiry-date parsing and validation
- User accounts, ABHA linkage, Firebase sync
- Vaccination schedules and reminders
- CoWIN, IDSP, or other government API integrations
- Nearby health-centre search
- Production multilingual content
- Admin portal and outbreak alert system

Do not claim these planned features are working until they are implemented, tested, and documented.
